# Practicum_projects:

1. **«Яндекс Самокат»**<br>
Сервис, который позволяет арендовать электрический самокат на несколько дней. Составил MindMap требований, спроектировал тест кейсы с использованием классов эквивалентности и граничных значений, провёл функциональное тестирование мобильного приложения на реальном устройстве и эмуляторе, тестирование API через Postman, проверил адаптивную вёрстку и валидацию форм, завёл баг репорты, в работе применял нейросети для генерации тест кейсов и анализа требований на этом проекте. Нашёл более 50 багов, из них 5 критических, сократил количество проверок в UI тестах на 20 %. Инструменты: DevTools, Postman, Charles, Cygwin64 Terminal, Android Studio, SQL;

2. **«Яндекс Прилавок»**<br>
Сервис для предпринимателей и компаний, который помогает запускать и вести виртуальные магазины: создавать витрины, управлять товарами, обрабатывать заказы и подключать онлайн оплату. Спроектировал тест кейсы с использованием классов эквивалентности и граничных значений, провёл тестирование API через Postman, завёл баг репорты, в работе применял нейросети для генерации тест кейсов и анализа требований на этом проекте. Нашёл более 30 багов, из них 4 критических, сократил количество проверок в API тестах на 20 %. Инструменты: DevTools, Postman, Charles, Cygwin64 Terminal;

3. **«Яндекс Метро»**<br>
Сервис, который позволяет планировать поездки на метро: строит маршруты между станциями, рассчитывает время в пути с учётом пересадок, а также показывает схемы метрополитенов разных городов. Спроектировал тест кейсы, провёл функциональное тестирование мобильного приложения на реальном устройстве и эмуляторе, проверил адаптивную вёрстку, завёл баг репорты, в работе применял нейросети для генерации тест кейсов и анализа требований на этом проекте. Нашёл более 20 багов, из них 3 критических, сократил количество проверок в UI тестах на 20 %. Инструменты: Postman, Android Studio.
